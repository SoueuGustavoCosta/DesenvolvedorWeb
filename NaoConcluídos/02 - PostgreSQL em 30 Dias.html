Antes do dia 01: instale o PostgreSQL
    Onde escrever o SQL
    pgAdmin 4 (recomendado no começo)

    Vem junto na instalação. Botão direito no banco → Query Tool. F5 executa tudo; selecione um trecho e F5 roda só ele. Ctrl+S salva o arquivo e F7 mostra o plano (EXPLAIN).

    VS Code

    Instale a extensão PostgreSQL (da Microsoft), conecte em localhost, porta 5432, usuário postgres. Ctrl+Shift+E executa. Bom para quem já pratica no VS Code.

    psql (terminal)

    O terminal do PostgreSQL. Você aprende no dia 25: psql -U postgres -d estudos. Todo profissional usa no dia a dia.
